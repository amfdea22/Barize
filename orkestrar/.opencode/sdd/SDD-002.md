# SDD-002: Recuperar Registros e Imagens no Sistema

**Status**: `draft`
**Autor**: architect + ui-designer
**Criado em**: 2026-07-30

---

## 1. Contexto

Auditoria completa revelou que 8 produtos seed existem com emoji mas **zero com `foto_url`**. Há 52 imagens em `backend/app/uploads/` — **nenhuma associada a produtos**. Cinco endpoints backend, dois scripts Python, dois types TypeScript e quatro páginas frontend omitem ou não exibem campos de imagem.

## 2. Objetivos e Não-Objetivos

- **Goals**:
  - Todo produto com `foto_url` apontando para imagem real
  - Toda página e endpoint relevante exibindo imagens com fallback de 3 níveis
  - UI Admin para vincular imagens a produtos
  - Scripts robustos (lêem DB path do `.env`)

- **Non-goals**:
  - Não redesenhar pipeline de upload
  - Não adicionar crop/editing de imagem
  - Não migrar para cloud storage

## 5. Componente Compartilhado

Criar `frontend/src/components/ProductThumbnail.tsx`:

```tsx
export default function ProductThumbnail({ foto_url, imagem, size = 'md', alt = '' }: Props) {
  const dims = { sm: 'size-6', md: 'size-7', lg: 'size-8', xl: 'size-28' };
  const emojis = { sm: 'text-xs', md: 'text-sm', lg: 'text-lg', xl: 'text-4xl' };
  const icons = { sm: 12, md: 14, lg: 16, xl: 32 };

  return (
    <div className={`${dims[size]} rounded-lg overflow-hidden bg-[var(--color-surface-container-high)] shrink-0`}>
      {foto_url ? (
        <img src={foto_url} alt={alt} className="w-full h-full object-cover" loading="lazy" />
      ) : imagem ? (
        <div className="w-full h-full flex items-center justify-center">
          <span className={emojis[size]}>{imagem}</span>
        </div>
      ) : (
        <div className="w-full h-full flex items-center justify-center">
          <ShoppingCart size={icons[size]} className="text-[var(--color-outline)]/40" />
        </div>
      )}
    </div>
  );
}
```
