# /direto <pergunta>

Responde uma pergunta ou solicitação de forma direta, sem ativar o workflow determinístico.

## Comportamento

- Bypass completo do workflow (planejamento, revisão, testes, merge)
- Resposta rápida: análise, explicação, pesquisa, sugestão
- NÃO modifica arquivos nem executa comandos de build/teste
- Útil para: dúvidas rápidas, explicações, análise de código, discussão técnica

## Exemplo

```
/direto Como funciona o sistema de plugins do Orkestrar?
```
