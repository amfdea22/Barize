# /tutorial

Inicia o tutorial interativo do Orkestrarr para novos usuários.

## Execução

1. Executar `Orkestrarr tutorial` (CLI interativo)
2. O tutorial guia o usuário por 7 passos:
   - Passo 1: Boas-vindas e visão geral
   - Passo 2: Configuração do `Orkestrarr.yaml`
   - Passo 3: Agentes e seus papéis
   - Passo 4: Skills — conhecimento especializado
   - Passo 5: Comandos e Workflows
   - Passo 6: Sistema de Memória Persistente
   - Passo 7: Próximos passos e documentação
3. Cada passo requer confirmação do usuário para avançar
4. Ao final, sugerir: "Execute /doctor para validar seu ambiente!"

## Guardrails

- **COMANDO INTERATIVO. Aguardar input do usuário entre passos.**
- **NÃO modificar configuração durante o tutorial.**

## Exemplo

```
/tutorial
→ 🚀 Bem-vindo ao Orkestrarr!
→ Este tutorial vai te guiar pelos conceitos fundamentais...
```
