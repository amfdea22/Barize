Acessibilidade

Pressione Tab para navegar entre os botões. O foco visível (2px primary, outline-offset 2px) aparece em todos os elementos interativos.

Dark Mode

O componente usa variáveis CSS que se adaptam automaticamente ao dark mode. Adicione a classe dark ao elemento pai para testar.

♿ Acessibilidade: Todos os botões possuem aria-label descritivo, suporte a navegação por teclado (Tab, Enter, Space), foco visível com :focus-visible, e estado aria-busy para loading. Contraste mínimo 4.5:1 em todas as variações (WCAG AA).
