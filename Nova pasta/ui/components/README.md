# UI Components — Tailwind CSS

> Gerado pelo orkestrar UI Design System Harness

Esta pasta contém templates de componentes UI usando **Tailwind CSS**.

## Como usar

1. Copie o HTML do componente desejado para seu arquivo de componente
2. Adapte as classes conforme necessário para seu framework (React, Vue, etc.)
3. Substitua os textos de exemplo pelo conteúdo real

## Componentes

| Arquivo | Descrição |
|---------|-----------|
| `input.html` | Campo de entrada de texto com label, placeholder, erro e suporte a ícones. |
| `button.html` | Botão interativo com múltiplas variantes e estados. |
| `card.html` | Container com superfície elevada para agrupar conteúdo. |
| `modal.html` | Janela modal com overlay, foco preso e suporte a teclado. |
| `navbar.html` | Barra de navegação superior responsiva com menu mobile. |
| `sidebar.html` | Barra lateral de navegação com colapso e submenus. |
| `table.html` | Tabela de dados com cabeçalho, linhas zebradas e responsividade. |
| `tabs.html` | Navegação por abas com painéis de conteúdo. |
| `form.html` | Estrutura de formulário com labels, inputs e validação. |
| `badge.html` | Rótulo pequeno para status, contagem ou categorias. |
| `alert.html` | Mensagem de feedback para ações do usuário. |
| `toast.html` | Notificação temporária no canto da tela. |
| `progress.html` | Barra de progresso para operações assíncronas. |
| `skeleton.html` | Placeholder animado enquanto conteúdo carrega. |
| `dropdown.html` | Menu suspenso com opções selecionáveis. |
| `accordion.html` | Seções expansíveis com animação de altura. |
| `pagination.html` | Navegação entre páginas de conteúdo. |
| `breadcrumb.html` | Navegação hierárquica com links de retorno. |
| `avatar.html` | Foto ou iniciais do usuário com indicador de status. |
| `empty-state.html` | Estado vazio com ilustração, mensagem e CTA. |

## Acessibilidade

- Todos os componentes incluem atributos `role`, `aria-*` e suporte a teclado
- Contraste mínimo 4.5:1 para texto normal
- Estados de foco visíveis em elementos interativos

## Dark Mode

Suportado via classes `dark:` (Tailwind) ou `.dark` CSS.
