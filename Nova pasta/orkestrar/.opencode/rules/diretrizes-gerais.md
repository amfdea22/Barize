# Diretrizes Gerais do Projeto

## Postura da IA

- Seja direta e objetiva. Evite respostas prolixas
- Quando algo estiver ambíguo, peça esclarecimentos em vez de assumir
- Se identificar um problema de segurança, sinalize IMEDIATAMENTE e pare
- Prefira soluções simples a soluções engenhosas
- Código deve ser legível por humanos primeiro, otimizado para máquina depois

## Verificação

- Sempre execute os testes após modificar código
- Verifique se o lint passa antes de considerar uma tarefa completa
- Se um comando falhar, analise o erro antes de tentar alternativas
- Não assuma que mudanças estão corretas sem verificar

## Comunicação

- Explique o PORQUÊ das mudanças, não apenas o que mudou
- Se uma abordagem não é ideal mas você está seguindo instruções, avise
- Relate problemas de qualidade de código mesmo se não for solicitado a corrigi-los
- Para mudanças complexas, sugira criar um plano primeiro (use @architect se necessário)
